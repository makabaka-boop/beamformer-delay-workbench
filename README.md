# PCM16 多轨对齐混音（纯浏览器本地处理）

在浏览器内导入 2～6 路**采样率相同的单声道 PCM16 WAV**，以第 1 路为基准做
整数采样延时对齐、逐样本混音，并可试听 / 下载结果。**音频全程不出本机**：
解析、相关分析、混音均在页面与 Web Worker 内完成，没有任何网络请求。

## 运行

Worker 不能从 `file://` 直接加载，请用任意静态服务器打开：

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 测试

```bash
npm test          # 即 node --test，无需安装依赖
```

## 规则与约定

| 项目 | 规则 |
| --- | --- |
| 搜索窗口 | 每路开头至多 4096 个采样 |
| 延时范围 | −32～+32 个**整数采样**，穷举 |
| 相关性 | 按交叠位置逐样本乘积直接求和（不归一化） |
| 并列裁决 | 先取延时绝对值最小，再取延时数值最小（负向优先） |
| 增益 | 四分之一整数倍（0.25 步进），输入会被量化（如 0.3 → 0.25） |
| 合成 | 逐样本相加，越界补零；四舍五入后饱和截断到 PCM16 范围 |
| 试听/下载 | 同一个 Worker 合成 ArrayBuffer → 同一个 Blob URL |
| 取消 | 重新导入或改参数即换代，旧分析/旧合成在让出点退出；主线程按代际号丢弃迟到结果 |

延时符号约定：`d > 0` 表示该路相对第 1 路**右移（延后）d 个采样**，
合成关系为 `out[n] = Σ samples_j[n − d_j] · gain_j`。

## 文件

- `core.js` — 无 DOM 依赖的算法核心：相关性、延时搜索、混音、WAV 解析/编码、会话代际（UMD，可在 Worker 与 Node 中加载）
- `worker.js` — Web Worker：装载 / 分析 / 合成，协作式取消（同构于 Node 测试）
- `app.js` + `index.html` + `styles.css` — 页面、导入、参数覆写、试听与下载
- `test/core.test.js` — 18 个用例：短数组穷举相关性、负/正延时、并列裁决、端点补零、四分之一增益、饱和、WAV 往返，以及会话/Worker 取消竞争
