# 多轨 PCM16 本地对齐合成

纯浏览器端工具：导入 2～6 路**采样率相同的单声道 16-bit PCM WAV**，以第一路为基准做整数采样延时对齐、可覆写延时与四分之一整数倍增益，逐样本合成后试听并下载 WAV。**音频全程不出本机**（Worker 内解析计算，无任何网络请求）。

## 运行

模块 Worker 需通过 http 提供（不能直接双击用 `file://` 打开）：

```bash
cd /workspace
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/
```

## 操作

1. 一次选择 2～6 个单声道 PCM16 WAV（采样率必须一致）。
2. 自动分析：在每路开头至多 4096 个采样上，穷举 −32～32 的整数延时，
   分数为交叠位置的逐样本乘积之和；并列时先取延时绝对值最小、再取数值最小。
3. 可勾选「覆写」手动指定某路延时（−32～32），增益按 0.25 步进（0～4）。
4. 改参后自动重新合成；试听与下载使用**同一份**合成缓冲（Int16Array）。

延时约定：输出位置 n 取 `cur[n - delay]`；正延时开头补零（该轨延后），负延时结尾补零（该轨提前）。越界一律补零，累加后四舍五入并夹取到 PCM16 范围。

## 取消竞争

- Worker 内为合并式队列（至多一个 active + 一个 pending；pending 同时携带至多一个 load 与一个最新 op），任务在开始前、每路之间和累加检查点发现自己被顶替即中止且**不回发结果**。
- 主线程另有 load / op 双代际令牌门，迟到的 analyzed / mixed 一律丢弃，不会替换当前试听。

## 文件

- `js/core.js`：纯函数（相关性搜索、合成饱和、WAV 解析/编码、令牌门）
- `js/engine.js`：环境无关的任务调度状态机（Worker 与测试共用）
- `js/worker.js`：Web Worker 封装
- `js/app.js` / `index.html`：UI
